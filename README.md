# RDC — Remote Desktop Control

Lightweight, low-latency cross-platform remote desktop written in Zig.

Лёгкий и быстрый удалённый рабочий стол на Zig: один небольшой бинарник для macOS, Windows и Linux, затем Android, iOS и браузер.

> Статус: проектирование, кода пока нет. Архитектура, протокол и этапы — в [docs/PLAN.md](docs/PLAN.md).

## Цели

- Задержка в локальной сети от захвата до показа — до 16 мс.
- Бинарник до 3 МБ на Windows и Linux, до 6 МБ на macOS; без установщика, рантаймов и библиотек рядом.
- Неподвижный экран — ноль кадров и почти ноль трафика.
- Сквозное шифрование (Noise поверх UDP): сервер и реле не видят ни картинку, ни ввод.
- Ни одно действие пользователя не теряется и не задваивается; сбой любой части — пауза, а не обрыв.
- Свой сервер ID и реле — один статический бинарник для любого VPS.
