RDC for AI agents, and the first Windows build.

- `rdc mcp` — an MCP server: an agent connects to a computer by the link from its RDC window, sees screenshots and uses the mouse and keyboard there (`connect`, `screenshot`, `click`, `move`, `drag`, `scroll`, `type`, `key`, `wait`, `devices`, `disconnect`). Works over stdio and over Streamable HTTP (`--http`), with a tunnel for cloud agents (`--tunnel`).
- Plugins: Claude Code (`claude plugin marketplace add ANODs/RDC`), Claude Desktop (`rdc-mcp.mcpb`), Codex (`codex plugin marketplace add ANODs/RDC`), and a skill that teaches the agent how to work through RDC.
- The person at the computer sees "AI agent …" in the RDC window and in the browser viewer and can stop it with one click.
- Text input: viewers and agents type Unicode text whatever the keyboard layout on the host.
- Windows: `RDC.exe` — the host on a PC (JPEG for now).
- The whole project is in English.

Installation: macOS — unzip, move RDC.app to Applications and allow Screen Recording and Accessibility. Windows — download `RDC.exe` and run it.
