RDC has an icon.

- The app on macOS, `RDC.exe` and its window on Windows, the browser tab and the home-screen icon on phones, the Claude Desktop extension and the Claude Code and Codex plugins all show it.
- The extension for Claude Desktop (`rdc-mcp.mcpb`) carries its icon and is otherwise the 0.3.0 server.

Installation: macOS — unzip, move RDC.app to Applications and allow Screen Recording and Accessibility. Windows — download `RDC.exe` and run it. Claude Desktop — open `rdc-mcp.mcpb`.
