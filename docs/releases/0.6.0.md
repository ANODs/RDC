A relay for networks that will not connect directly, Settings on Windows, and RDC on Linux.

- **Relay.** When a phone and the computer cannot connect directly — strict NAT on mobile data or a VPN — the page switches to a relay on Cloudflare after about 10 seconds, and reconnects through it at once after that. Everything is sealed end to end (AES-256-GCM, numbered messages): the relay sees only noise. RDC uses its own relay by default; **Settings → Relay** picks your own or turns it off. Your own takes a couple of minutes on a free Cloudflare account: a Deploy to Cloudflare button or `npx wrangler deploy` — see `relay/README.md` in the repository.
- **Windows: Settings…** with permanent access (the authenticator code is shown after your Windows password), Start RDC at login (no UAC prompt when RDC runs as administrator), Keep this PC awake and the relay choice. New, not yet run on a PC.
- **Linux (X11): RDC as a host.** `rdc-linux-x86_64` below — a single binary with a GTK window and the same settings, capture through MIT-SHM, its own JPEG encoder, XTest input; it updates itself. Wayland sessions, H.264 and `rdc mcp` on Linux are not there yet.
- `--relay URL|off` sets the relay for one run.

Installation: macOS — unzip, move RDC.app to Applications and allow Screen Recording and Accessibility. Windows — download `RDC.exe` and run it. Linux — download `rdc-linux-x86_64`, `chmod +x` it and run it in an X11 session. Claude Desktop — open `rdc-mcp.mcpb`.
