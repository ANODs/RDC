Several displays, a new look, and the site at rdc.timoshkin.dev.

- **Several displays.** The viewer shows one display at a time, full size, and follows the pointer: when it moves onto another display — dragging a window there, say — the picture switches by itself. Hold the mouse button and move past the edge of the picture to carry the pointer, and the window, onto the next display. A **Display 1/2** button switches by hand when there are two or more. AI agents get a `display` tool (`rdc_display` in WebMCP), and `devices` lists the displays.
- **A new look.** The RDC window and Settings on macOS are redone with a dark theme and fewer controls; the viewer page is restyled.
- **The site:** https://rdc.timoshkin.dev — the viewer, and pages about RDC in English, Russian and Chinese. Links from anywhere now open there; the older https://anods.github.io/RDC/ links keep working.
- Checked on macOS with a second, virtual display; on Windows and Linux several displays are built but not yet tried on a real machine.

Installation: macOS — unzip, move RDC.app to Applications and allow Screen Recording and Accessibility. Windows — download `RDC.exe` and run it. Linux — download `rdc-linux-x86_64`, `chmod +x` it and run it in an X11 session. Claude Desktop — open `rdc-mcp.mcpb`.
