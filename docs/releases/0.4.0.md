The phone becomes the computer's microphone — and, on Windows 11, its camera.

- **Phone microphone on a Mac.** The viewer's new **Camera and mic** button lends the phone's microphone to the computer. There it is "RDC Microphone", an ordinary input device in System Settings → Sound and in every app's list: in the Claude app, pick RDC Microphone and record a voice message through the phone. Turn it on once with **Enable phone microphone** in the RDC window (the administrator password; sound pauses for a second); remove it in Settings or with `rdc mic remove`. While it streams, the RDC window shows "Phone microphone live" with a **Stop** button.
- **Phone camera on Windows 11.** "RDC Camera", a virtual camera any app can pick. RDC registers it when it runs as administrator, or with **Enable phone camera** in its window (`rdc camera install|remove` from a terminal). Built, not yet run on a PC.
- Lend devices from the **From anywhere** link: browsers give the microphone and camera only to secure pages. Audio travels as 48 kHz PCM and video as JPEG frames, over the same connection as the screen; the microphone arrives 70 ms later with the browser on the same Mac, about 100 ms on a home network, under 300 ms on mobile data.
- Not available: a phone camera on a Mac (macOS takes cameras only from an extension signed with a paid Apple developer account) and a phone microphone on Windows (it needs a kernel driver).
- **Windows: RDC starts as administrator** (the UAC prompt at launch), so clicks and keys reach apps that run as administrator — Task Manager, installers — and RDC adds its own Windows Firewall rule for viewers. Declined, it runs with your rights; `rdc mcp` never asks.
- Windows: the RDC window opens while the Claude Desktop extension runs — install its 0.4.0 `rdc-mcp.mcpb`; with the older one RDC quietly exited. A second launch brings the running window forward.
- Viewer: Esc on your keyboard ends the session; the Esc of the on-screen keyboard is the one that reaches the computer.

Installation: macOS — unzip, move RDC.app to Applications and allow Screen Recording and Accessibility. Windows — download `RDC.exe` and run it. Claude Desktop — open `rdc-mcp.mcpb`.
