AI agents reach computers from anywhere; WebMCP on the viewer page.

- **`rdc mcp` takes every link from the RDC window.** The link from anywhere (`https://anods.github.io/RDC/#<code>-<key>`) works across networks: the agent finds the computer through public servers and meets it on its relay. The permanent link (`…#my-<key>`) works too, with the current 6-digit authenticator code passed as `code` — the agent asks the user for it. The computer needs RDC 0.6.2 or newer for this; the agent says so when it is older.
- **WebMCP.** The viewer page at https://anods.github.io/RDC/ gives an AI agent in the browser the tools `rdc_connect`, `rdc_status`, `rdc_screenshot`, `rdc_click`, `rdc_move`, `rdc_scroll`, `rdc_type`, `rdc_key` and `rdc_disconnect`, where the browser supports WebMCP (Chrome's origin trial).
- Relay: a video frame through the relay could overflow the receiving end's buffer; fixed.

Installation: macOS — unzip, move RDC.app to Applications and allow Screen Recording and Accessibility. Windows — download `RDC.exe` and run it. Linux — download `rdc-linux-x86_64`, `chmod +x` it and run it in an X11 session. Claude Desktop — open `rdc-mcp.mcpb`.
