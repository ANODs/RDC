The first public build of RDC for macOS (Apple Silicon).

- Your Mac's screen in a browser on any device on the same network, via a link or a code.
- Mouse and keyboard control. On phones, a touchpad mode: tap for left click, double tap for right click, two fingers to scroll.
- An on-screen keyboard that matches the computer's OS: move it, dock it at the bottom or hide it.
- H.264 via WebCodecs where the browser supports it, JPEG otherwise.
- Automatic updates from GitHub Releases with signature verification (Settings → "Update automatically").

To install, unzip the archive, move RDC.app to Applications and grant it the Screen Recording and Accessibility permissions.
