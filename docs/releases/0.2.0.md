Первая публичная сборка RDC для macOS (Apple Silicon).

- Экран Mac — в браузере на любом устройстве в той же сети, по ссылке или коду.
- Управление мышью и клавиатурой; на телефоне — режим тачпада: тап — левый клик, двойной тап — правый, два пальца — прокрутка.
- Экранная клавиатура под ОС компьютера: перемещается, закрепляется внизу, прячется.
- H.264 через WebCodecs, где браузер его даёт, иначе JPEG.
- Автообновление из релизов GitHub с проверкой подписи (Настройки → «Обновлять автоматически»).

Установка: распакуйте архив, перенесите RDC.app в «Программы» и разрешите ему «Запись экрана» и «Универсальный доступ».
