Your own Mac, reachable when no one is at it.

- **Permanent access** (macOS; off by default, in Settings ⌘,). A link of your own that never changes. Whoever opens it must enter the current 6-digit code from an authenticator app (Google Authenticator, 1Password, any TOTP app), so the link alone lets no one in. **Set up the phone…** shows two QR codes: the link for the phone's camera, and the key for the authenticator app — that one only after Touch ID or your password. A code works once; after 5 wrong codes the link waits half a minute, after 20 a day. The browser tab stays signed in for 12 hours, so a dropped connection does not ask for a new code. **New link and key…** replaces both.
- **Start RDC at login** (Settings): RDC starts hidden when you log in and keeps running when its window is closed.
- **Keep this Mac awake** (Settings): a sleeping computer cannot be reached. The display may still turn off; a MacBook with its lid closed sleeps anyway.
- Phone camera: starts in **Light** quality (640×360, 10 frames a second) so the phone stays cool; **HD** is one tap away in the Camera and mic panel.
- With all of these off RDC works as before. Windows does not have these settings yet.

Installation: macOS — unzip, move RDC.app to Applications and allow Screen Recording and Accessibility. Windows — download `RDC.exe` and run it. Claude Desktop — open `rdc-mcp.mcpb`.
