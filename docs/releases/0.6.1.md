A fix for 0.6.0 on macOS.

- **macOS: 0.6.0 would not open** on any macOS older than 26.7.2 ("This version of RDC cannot be used with this version of macOS"): the release was built on a newer CI machine, and its macOS version became the minimum. Builds now always name macOS 14.4 as the minimum, as before.
- If your Mac updated to 0.6.0 and RDC no longer opens, download `RDC-0.6.1-macos-arm64.zip` below and put RDC.app in place of the old one — 0.6.0 cannot update itself there. Permissions (Screen Recording, Accessibility) stay.
- Otherwise the same as 0.6.0.

Installation: macOS — unzip, move RDC.app to Applications and allow Screen Recording and Accessibility. Windows — download `RDC.exe` and run it. Linux — download `rdc-linux-x86_64`, `chmod +x` it and run it in an X11 session. Claude Desktop — open `rdc-mcp.mcpb`.
